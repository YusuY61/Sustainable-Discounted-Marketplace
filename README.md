# Sustainable Discount Marketplace

A full-stack web application built for the CTIS256 course at Bilkent 
University. Local markets list near-expiry products at discounted prices, 
and consumers in the same city can browse them, add them to a cart, and 
complete a simulated purchase. The aim is to reduce food waste.

This was a team project, built together with Adil Eren Aydogan, Halis Mert Altın, and Ozan Aydemir. This 
repository is a copy I maintain for portfolio purposes, with the team's 
permission.

## My Contributions
- Designed the user interface for the application
- Built the market and consumer dashboards
- Implemented features such as product editing and updating
- Took part in the overall project planning

## Tech Stack
Node.js, Express.js, EJS, MySQL, JavaScript, HTML, CSS, bcrypt, 
express-session, express-validator, Multer, Nodemailer, Docker Compose

## Features
- Role-based authentication (market and consumer roles)
- Email verification at registration
- Secure password hashing with bcrypt
- Product management with image upload (markets)
- Location-based product filtering, search, and pagination (consumers)
- Dynamic cart with stock validation
- Simulated purchase flow

## Note
This is an academic prototype, not a production-ready e-commerce system. 
There is no real payment integration; the focus is on core marketplace 
features, authentication, and shopping-cart logic.
